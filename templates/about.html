{{ t('About Janaushadhi Saathi') }}

{% if lang == 'hi' %} भारतीय नागरिकों के लिए जेनेरिक दवाइयों, कीमतों और जन औषधि केंद्रों की सार्वजनिक जानकारी को सरल और ईमानदार तरीके से समझाने की एक स्वतंत्र परियोजना। {% else %} An independent project that makes public information about generic medicines, prices and Jan Aushadhi Kendras easier to understand. {% endif %}

{% if lang == 'hi' %}हमारा उद्देश्य{% else %}Our purpose{% endif %}

{% if lang == 'hi' %}

किफायती जेनेरिक दवाइयाँ खोजना, सही संघटन और मात्रा समझना, ब्रांड और जेनेरिक कीमत की सावधानीपूर्वक तुलना करना, और आधिकारिक जन औषधि केंद्र की जानकारी तक पहुँचना आसान बनाना।

हम जानकारी को उसके स्रोत और सत्यापन स्थिति के साथ दिखाते हैं। नमूना डेटा को कभी आधिकारिक नहीं बताया जाता।

{% else %}

To make it easier to find affordable generic medicines, understand composition and strength, compare a branded price carefully, and reach official Jan Aushadhi Kendra information.

We show information with its source and verification status. Sample data is never labelled official.

{% endif %}
