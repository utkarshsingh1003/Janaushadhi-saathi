{% else %}

No. This is an independent information project. It is not affiliated with PMBJP or PMBI and does not claim to be a government application. For official information, use janaushadhi.gov.in.

{% if lang == 'hi' %}दिखाई गई कीमतें आधिकारिक हैं?{% else %}Are the prices official?{% endif %} {% if lang == 'hi' %}

इस संस्करण में दवाओं की कीमतें नमूना हैं और आधिकारिक एमआरपी नहीं हैं। हर कीमत के साथ “नमूना डेटा” या “सत्यापित नहीं” दिखाया जाता है। आधिकारिक उत्पाद और एमआरपी सूची के लिए पीएमबीजेपी की डाउनलोड या उत्पाद पृष्ठ देखें।

{% else %}

The medicine prices in this build are sample values, not official MRPs. Each price is labelled “Sample data” or “Not verified”. For official product and MRP lists, use the PMBJP downloads or product pages.

{% endif %}
{% if lang == 'hi' %}क्या मैं इस साइट से दवा खरीद सकता हूँ?{% else %}Can I buy medicines through this site?{% endif %} {% if lang == 'hi' %}

नहीं। यह कोई ऑनलाइन दुकान नहीं है। यह ऑर्डर, होम डिलीवरी या भुगतान नहीं करता। दवा के लिए किसी वैध फार्मेसी या जन औषधि केंद्र से संपर्क करें।

{% else %}

No. This is not an online shop. It does not take orders, arrange home delivery or process payments. For medicines, use a lawful pharmacy or Jan Aushadhi Kendra.

{% endif %}
{% if lang == 'hi' %}क्या यह बता सकता है कि कौन-सी दवा मेरे लिए सही है?{% else %}Can it tell me which medicine is right for me?{% endif %} {% if lang == 'hi' %}

नहीं। यह निदान, खुराक या इलाज की सलाह नहीं देता। अपनी पर्ची का पालन करें और योग्य डॉक्टर या फार्मासिस्ट से सलाह लें।

{% else %}

No. It does not diagnose, prescribe or advise on treatment. Follow your prescription and consult a qualified doctor or pharmacist.

{% endif %}
{% if lang == 'hi' %}दो दवाएँ एक जैसी क्यों नहीं दिख रहीं, जबकि नाम मिलता है?{% else %}Why are two similarly named medicines not shown as a match?{% endif %} {% if lang == 'hi' %}

क्योंकि मिलान केवल नाम से नहीं होता। संघटन, मात्रा, दवा का रूप, मार्ग और रिलीज़ प्रकार भी जाँचे जाते हैं। अलग मात्रा या अलग रिलीज़ प्रकार को सुरक्षा कारण से अस्वीकार किया जाता है।

{% else %}

Because matching is not based on the name alone. Composition, strength, dosage form, route and release type are also checked. A different strength or release mechanism is rejected for safety.

{% endif %}
{% if lang == 'hi' %}केंद्र का पता और फ़ोन नंबर कहाँ से आया?{% else %}Where do Kendra addresses and phone numbers come from?{% endif %} {% if lang == 'hi' %}

इस संस्करण में केंद्र रिकॉर्ड नमूना हैं; वे असली पते या फ़ोन नंबर नहीं हैं। असली केंद्र की पुष्टि के लिए आधिकारिक लोकेटर का उपयोग करें।

{% else %}

Kendra records in this build are samples; they are not real addresses or phone numbers. Use the official locator to confirm a real Kendra.

{% endif %}
{% if lang == 'hi' %}मेरी अपलोड की गई पर्ची कहाँ जाती है?{% else %}What happens to a prescription image I upload?{% endif %} {% if lang == 'hi' %}

छवि केवल मेमोरी में संसाधित होती है और सहेजी नहीं जाती। निकाला गया टेक्स्ट भी मेडिकल इतिहास के रूप में संग्रहीत नहीं होता। कृपया संवेदनशील जानकारी वाली पर्ची अपलोड न करें।

{% else %}

The image is processed in memory only and is not saved. Extracted text is not stored as a medical history. Please do not upload a prescription containing sensitive information you do not want processed.

{% endif %}

{% else %}

{% endif %}
