{% if lang == 'hi' %}रिपोर्ट और अवधि{% else %}Reports and retention{% endif %}

{% if lang == 'hi' %}

रिपोर्ट फ़ॉर्म से भेजा गया संदेश, चुनी गई श्रेणी, पृष्ठ और वैकल्पिक संपर्क विवरण SQLite डेटाबेस में अधिकतम 365 दिन रखा जाता है। 365 दिन से पुरानी प्रविष्टियाँ ऐप शुरू होने पर हटा दी जाती हैं। IP पता संदेश के साथ नहीं रखा जाता। कृपया पर्ची या निजी चिकित्सा जानकारी न लिखें।

{% else %}

A report message, category, page and optional contact detail are stored in a SQLite database for up to 365 days. Entries older than 365 days are deleted when the app starts. The IP address is not stored with the message. Please do not include prescriptions or personal medical information.

{% endif %}

{% if lang == 'hi' %}होस्टिंग और लॉग{% else %}Hosting and logs{% endif %}

{% if lang == 'hi' %}

होस्टिंग प्रदाता तकनीकी रूप से अनुरोध का IP पता और समय देख सकता है। एप्लिकेशन लॉग में केवल HTTP विधि, पथ, स्थिति और समय होता है — खोज शब्द, पर्ची टेक्स्ट या फ़ॉर्म सामग्री नहीं।

बाहरी सरकारी लिंक और OpenStreetMap नक्शा केवल तब खुलते हैं जब आप उन पर क्लिक करते हैं। उनकी अपनी गोपनीयता नीतियाँ लागू होती हैं।

{% else %}

The hosting provider can technically see request IP addresses and times. Application logs contain only the HTTP method, path, status and duration — never search terms, prescription text or form content.

External government links and OpenStreetMap maps open only when you choose them. Their own privacy policies apply.

{% endif %}
